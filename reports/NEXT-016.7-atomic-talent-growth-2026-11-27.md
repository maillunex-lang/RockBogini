# NEXT-016.7: атомарное повышение талантов героев, 2026-11-27

## Что исправлено
- Устранена частичная потеря валюты/предметов, когда один из следующих материалов отсутствует.
- При обучении с героями-материалами исключено их удаление до гарантированного полного списания и фиксации уровня таланта.
- PostgreSQL транзакция: блокировка профиля и затронутых героев, повторная проверка текущего уровня таланта и соответствия героев, возврат материалов, списание предметов, удаление героев и сохранение нового уровня в одном COMMIT.
- При недоступном материале выполняется ROLLBACK, возвращается HTTP 409.
- Тесты: недостаток второго предмета при достаточном первом, сохранность баланса 200 единиц; успешный повтор с полным набором; ★5 герой-материал не исчезает при дефиците предметов и правильно поглощается при успехе.
- Изолированная PostgreSQL 16/Redis 7: 156/156 PASS, 0 FAIL, 0 SKIP, job piphto0sta, npm run build PASS.

## Открыто
- Аналогичные действия level, job, luck и reset ещё требуют транзакционной защиты от параллельных операций и частичного списания.
- Условия изменения формации во время покупки и персонажных операций проверены не полностью.
