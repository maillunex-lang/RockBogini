# NEXT-021.3D: Оригинальные формации «Бесконечной бездны»

## Источник
- Исходный серверный обработчик read-only `/home/gamedev/QueensBladeH5/racon2-main/server/lib/racon/game/handlers/pve_abyss.ex`.
- Исходный `FormationType` из Cocos-каталога, контрольная сумма SHA256: `reports/NEXT-021.3D-formation-source-audit.json`.
- Original EndlessAbyss MapType 10 = формации Sid 101/102/103, FormationType 901 для каждого выбора, боевой layout 902 с координатами (2,5,8), т.е. station indices (1,4,7). MapType 11 = формация Sid 7, прежняя полная команда.

## Изменения
- PostgreSQL migration 29: три отдельные сохраняемые SID в `player_formations.single_hero_ids` с защитой от дублей и ограничением массива.
- Бой в одиночном режиме теперь использует всех выбранных героев на трёх позициях оригинального layout 902, без прежней искусственной ротации по номеру волны.
- `GET /v1/abyss/formation`, `PUT /v1/abyss/formation`: серверное сохранение и чтение, проверка собственности на героев, уникальности SID, авторизация, запрет изменений при незавершённом бою.
- `GET /v1/abyss` дополнен безопасной информацией о выбранной тройке.
- В клиентской вкладке «Бездна» добавлен отдельный выбор трёх героев, сохранение и предупреждение о несохранённой формации. Основной отряд остаётся независимым.
- Для свежих аккаунтов одиночная формация по умолчанию пустая: игрок должен явно выбрать героев, чтобы избежать автоматического назначения чужих или неподходящих персонажей.
