# NEXT-021.3F: Усиления и пассивные навыки Бесконечной бездны

## Исходная реализация
- Исходный серверный обработчик read-only `/home/gamedev/QueensBladeH5/racon2-main/server/lib/racon/game/handlers/pve_abyss.ex`: `buffed/2`, `pick_buff/4`, `heal/4`, `offer/1`.
- Все 12 оригинальных `EndlessAbyssBuff` загружаются из ранее экспортированного `next-server/data/abyss-buffs.json`, без подмены или выдуманных бонусов.
- Type 3 (атрибуты): индекс ниже 100 добавляет указанную величину, 100-199 добавляет атрибуту index-100; индекс >=200 оригинальный код не применяет. В частности `buff 6` со значением `[205,80]` игнорируется.
- Type 2 (навыки): оригинал добавляет только отсутствующий skill ID к герою, пассивные навыки обрабатываются при начале раунда симуляции.
- Type 1 (лечение): оригинал лечит только героев с сохранённым положительным HP, в тысячных долях максимального здоровья; герои с нулём HP не воскресают.
- Параметр `Count=1` исключает повторное появление выбранного навыка в списке из трёх предложенных бонусов.

## Выполнено
- Правила из `abyssRoutes.ts` выделены в `next-server/src/abyssBuffRules.ts`, интегрированы в серверную симуляцию и транзакционные вызовы.

- `abyssBuffOptions` предлагает три различных бонуса и отбрасывает уже выбранные однократные усиления.
